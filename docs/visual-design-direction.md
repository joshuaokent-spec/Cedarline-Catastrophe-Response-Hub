# Visual Design Direction

## Goal

Create a visual language that feels meaningfully different from Cedarline's routine account and claims experiences without becoming sensational or alarmist.

## Palette

### Storm Navy — #102F38
Primary catastrophe-context background.

Why:
- differentiates the hub from routine Cedarline surfaces;
- supports high-contrast light text;
- feels serious without using danger-red as the dominant color.

### Safety Yellow — #F5C451
Immediate-attention accent.

Why:
- visually prioritizes safety;
- works for focus and caution;
- is intentionally not used for routine insurance actions.

### Cedar Green — #0B4A43
Insurance / recovery action color.

Why:
- reconnects the catastrophe experience to the established Cedarline brand;
- visually marks the transition from immediate danger to service tasks.

### Recovery Mist — #EEF4F2
Later-stage background.

Why:
- lowers visual intensity after urgent guidance;
- creates a visible shift from crisis to recovery.

## Illustration direction

The coded hero uses a custom vector scene:
- storm clouds;
- rain;
- lightning;
- a home;
- warm interior light;
- green recovery ground.

The image is an implementation SVG, not an Illustrator-authored asset.

A future Adobe pass should recreate/refine this as a master vector asset in Illustrator and export production SVG/PNG variants.

## Typography

Large, compact hero typography communicates urgency without all-caps alarm language.

Routine guidance returns to the Cedarline system typography and spacing.

## Hierarchy rule

The visual system should always reinforce the content order:

1. safety;
2. hazard context;
3. recovery sequence;
4. insurance documentation;
5. longer-term recovery.

The hero must not visually push “Start a claim” above immediate safety.
