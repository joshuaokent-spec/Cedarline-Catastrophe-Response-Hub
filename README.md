# Cedarline Catastrophe Response Hub

A responsive **catastrophe-response UX and visual-design case study** for the fictional Cedarline Mutual insurance experience.

**Visual design · Responsive web · Crisis UX · Content design · Accessibility · HTML/CSS/JavaScript · Adobe production planning**

> **Cedarline Mutual is fictional.** This project is an independent UX portfolio concept and does not provide emergency or insurance services.

## Project thesis

After severe weather, people may be dealing with immediate safety concerns, damaged property, power loss, displacement, missing information, and uncertainty about what to do first.

The UX problem is:

> **How can an insurer help people separate urgent safety actions from insurance tasks, understand what can wait, and move toward recovery without overwhelming them?**

## Portfolio role

This fifth Cedarline project is intentionally more visually expressive than the first four.

It is designed to demonstrate:

- crisis-oriented content hierarchy;
- responsive corporate web design;
- visual storytelling;
- branded illustration/icon direction;
- emergency-vs-insurance decision support;
- accessible high-stress interaction patterns;
- downloadable preparedness/recovery content;
- an honest Adobe asset-production workflow.

## Research integrity

The safety model is informed by public disaster guidance from organizations such as the American Red Cross.

The project does **not** claim:

- live emergency data;
- real insurer catastrophe operations;
- completed user interviews or usability studies;
- that coded SVG/CSS assets were authored in Adobe applications unless corresponding source files are actually created there.
